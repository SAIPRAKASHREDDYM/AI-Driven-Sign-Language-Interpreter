# AI-DRIVEN SIGN LANGUAGE INTERPRETER

## 1. Project Overview
The AI-Driven Sign Language Interpreter is a real-time hand gesture recognition system designed to reduce communication barriers between individuals who use sign language and people who are unfamiliar with it.

The system uses artificial intelligence, computer vision, and deep learning techniques to detect hand gestures through a webcam and display the recognized gestures as text in a web interface.

## 2. Problem Statement
Communication between sign language users and non-signers can be challenging because many people are unfamiliar with sign language. This project aims to develop an AI-based system that recognizes hand gestures in real time and displays the corresponding textual output.

## 3. Objectives
- Recognize supported hand gestures using a webcam.
- Detect and track hands in real time.
- Classify hand gestures using a trained deep learning model.
- Display recognized gestures as text.
- Develop a user-friendly browser-based interface.
- Demonstrate the application of AI and computer vision to accessible communication.

## 4. Technologies Used
- **Programming Language:** Python
- **Computer Vision:** OpenCV
- **Hand Detection and Tracking:** MediaPipe
- **Deep Learning:** TensorFlow and Keras
- **Numerical Processing:** NumPy
- **Backend:** Flask
- **Frontend:** HTML, CSS and JavaScript

## 5. System Workflow
1. Capture live video using the webcam.
2. Detect and track the hand using MediaPipe.
3. Process the captured frames or hand data.
4. Predict the hand gesture using the trained recognition model.
5. Display the predicted gesture as text in the web interface.

## 6. Key Features
- Real-time webcam-based hand gesture recognition.
- AI-based gesture classification.
- Hand detection and tracking.
- Textual display of recognized gestures.
- Browser-based user interface.

## 8. Installation and Execution

### Prerequisites
- Python installed on your system.
- A working webcam.
- Required Python packages.
- A supported web browser.

### Steps
1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Install the required dependencies:

   `pip install -r requirements.txt`

4. Run the Flask application using your actual entry-point filename. For example:

   `python app.py`

5. Open the local URL displayed in the terminal.
6. Allow webcam access when prompted.

**Note:** Adjust the commands according to your actual project files and setup.
